# Draft history

Every earlier draft is kept here in Markdown. Nothing is deleted — when a conclusion was withdrawn, the draft that carried it stays, and [`_CHANGELOG.md`](_CHANGELOG.md) records what was withdrawn and why.

**Read [`_CHANGELOG.md`](_CHANGELOG.md) before citing any file in this directory.** Several drafts carry explicit do-not-cite warnings on specific sections; the rest of those drafts remains accurate.

PDFs of superseded drafts are not stored, to keep the repository small. Any of them can be rebuilt from the Markdown:

```bash
python3.11 src/build_pdf.py v10      # rebuilds MANUSCRIPT_v10.pdf
```

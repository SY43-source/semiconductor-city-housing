# The New Gold Rush: Housing Transformation in the Age of Semiconductor Cities
## A Regression-Based Prediction Model for Pyeongtaek (2015–2025)

> 목적: 위 논문 제목에 부합하는 최적 방법론 추출 + 데이터 활용 극대화.

## 0. 한 문단 요약 (Abstract 초안)

반도체 산업 클러스터(삼성 평택 캠퍼스 P1 2017 / P2 2020 / P3 2022)의 형성이 주변지역
주거지의 물리적 형태를 어떻게 변화시켰는가를 평택시(2015–2025) 아파트 공급 데이터로
정량 분석한다. 면적·방수·용적률·건폐율·주차 등 주거 요소의 연도별 회귀 기울기를 추출하고,
분절회귀(segmented regression)로 변곡점이 공장 가동 시점과 정렬되는지 검정하며,
비(非)반도체 대조도시와의 이중차분(difference-in-differences)으로 "반도체 효과"를 분리한다.
연령 코호트 인구 유입과 주거 형태의 시차 상관을 결합해, 미래 반도체 신도시의 주거 수요를
예측하는 회귀식을 요소별로 제시한다. 방/거실 등 도면 내부 치수는 로컬 Vision LLM(Gemma)
기반 평면도 자동 디지털화로 추출하여 방법론적 기여를 더한다.

## 2. 이론적 틀 (왜 학술적으로 의미 있나)

- **집적경제(agglomeration economics)**: 산업 클러스터 → 노동 유입 → 주거 수요 변형.
  평택은 "산업 주도 급속 도시화(industry-led rapid urbanization)"의 자연실험.
- **노동 코호트 → 주거 형태 가설**: 20~40대 엔지니어 가족 유입 → 3~4방 가족형 수요 →
  대형 단지·주차 증가. (우리 데이터: 평택 25~34세 2011→24 +46~61%, 3~4방 95%)
- **일반화(generalizability)**: 평택은 사례. 용인(SK)·화성(삼성)·Austin(Samsung/Tesla)·
  Hsinchu(TSMC)·Dresden(ESMC/Infineon) 로 확장되는 **시대적 현상**의 한 관측점.

## 4. 방법론 (핵심 — 제안 #1 을 학술 수준으로 격상)

> 제안 #1 (기술통계 → 회귀 → overlay → 예측식) 은 좋은 뼈대. 아래 5가지를 추가하면
> 학부 과제 → 학술 논문 수준으로 격상된다.

### 4.1 기술통계 + 표준화 (제안 유지 + 보강)
- 연도별 평균/중앙값/분포 (박스플롯) — 요소별.
- ⭐ **표준화(z-score)**: 면적(m²)·용적률(%)·주차(대) 는 단위가 달라 기울기 직접 비교 불가.
  → 각 속성을 z-score 변환 후 "표준화 기울기" 로 **어느 속성이 가장 빠르게 변하나** 비교.

### 4.2 회귀 분석 (제안 유지 + 정정)
- 요소별 `속성 = β₀ + β₁·(연도)` 선형 + 필요시 2차/로그 (비선형 검토).
- β₁ = 연간 변화율. **신뢰구간(95% CI)** = 표준오차 기반 (← 이게 "표준편차 기반" 의 정확한 형태).
- R², p-value 로 추세 유의성 검정.

### 4.3 ⭐ 분절회귀 / 변곡점 검정 (제안의 "overlay" 를 통계로 격상)
- 단순 "P1/P2/P3 시점 겹쳐 보기" → **segmented regression (breakpoint analysis)**.
- 데이터가 스스로 변곡점을 찾게 하고, 그 변곡점이 공장 가동 시점(2017/2020/2022)과
  통계적으로 정렬되는지 검정.
- 도구: Python `piecewise-regression` 또는 `ruptures` 패키지.
- **의의**: "변화가 공장과 함께 가속됐다" 를 눈이 아닌 **통계로 입증**.

### 4.4 ⭐⭐ 이중차분 (Difference-in-Differences) — 인과 추론의 핵심
- 문제: 평택 변화가 반도체 때문인지, 전국 트렌드인지 구분 필요.
- 설계:
  - **처치군(treatment)** = 평택 (반도체)
  - **대조군(control)** = 비(非)반도체 인접 유사도시 (예: 안성시·오산시 — 경기 남부, 반도체 無)
  - **시점** = pre(2015~2016) vs post(2017~2025)
  - DiD 추정: `(평택_post − 평택_pre) − (대조_post − 대조_pre)` = 순수 반도체 효과.
- ⚠️ 서울은 대조군으로 부적합(재건축 도시 ≠ 신도시). **안성/오산이 더 깨끗한 counterfactual**.
- **의의**: "반도체가 원인" 을 학술적으로 방어 가능한 유일한 설계.

### 4.5 ⭐ 복합 주거현대화 지수 (Housing Modernization Index, novel)
- 5~7개 속성을 표준화 후 가중합 → 단일 "현대화 지수" 구축.
- 연도별 지수 추이 = 주거 변화를 한 곡선으로 요약 → 도시간 비교(평택 vs 대조 vs 국제) 용이.
- **의의**: 논문의 독창적 기여 (novel composite metric).

### 4.6 ⭐ 인구–주거 시차 결합 (RQ5, 두 데이터셋 연결)
- 평택 5세별 인구(2011~2025) × 주거 속성 시계열.
- 시차 교차상관(lagged cross-correlation): "30~40대 유입 → N년 후 대형·가족형 공급 증가?"
- **의의**: 두 독립 데이터(인구+주거)를 결합한 유일한 분석. "수요→공급" 메커니즘 시사.

### 4.7 예측식 도출 (제안 유지 + 외삽 한계 명시)
- 요소별 `y = f(연도) ± CI`. 2030/2035 예측치 + **신뢰구간 (외삽일수록 넓어짐)**.
- ⚠️ 정직성: "추세 지속 가정 시" 명시, 포화(saturation) 가능성 논의 (방수는 plateau 예상).

### 4.8 ⭐ Vision LLM 평면도 디지털화 (novel 방법론 기여)
- 방/거실 크기: NAVER 2D 도면 + 로컬 Vision LLM(Gemma) polygon → mm 추정.
- NH mm 도면(정답) 으로 정확도 검증 (MAE, ±%).
- **의의**: 도시연구용 평면도 자동 디지털화 = 방법론 자체가 논문 기여 (부록 또는 별도 절).

## 8. 한계 (정직하게 명시 = 학술 성실성)

1. 표본: 평택 2015~2025 robust (33단지). pre-2015 희소 → 장기추세는 참고.
2. 인과: DiD 로 방어하나 완전 무작위 아님(고덕신도시 정책 교란 잔존).
3. 공급 편향: 실거래 추가 전엔 "공급" 만 (수요·선호는 대리지표).
4. 외삽: 2030+ 예측은 신뢰구간 넓음. "시나리오" 로 표현.
5. OCR: 방/거실 크기 ±5~20% 오차 (Vision LLM 정확도 검증 후 사용).
6. 국제비교: 정량(Austin)+정성(Hsinchu/Dresden) 혼합 — 완전 대등 비교 아님.

## 10. 기대 기여 (논문 contribution)

1. **정량 실증**: 반도체 클러스터 → 주거 형태 변화의 회귀 기반 최초 정량 분석 (한국).

5. **일반화**: 반도체 도시 현상의 국제적 틀 제시.

> 핵심 연구질문 operationalize: "평택에서 어떤 평형·방개수가 활발히 거래되나 + 방/거실/부엌
> 크기가 분양시기별 어떻게 변하나 → 광주 반도체 근로자 아파트 공간 예측".
> 데이터: 실거래가 253k + 인구 8지역 + 아파트 6,244 + 평면도 118.

### 13.1 거래 활발 규격 분석 (실거래가 253k) — [실증 완료]
- 방법: 실거래 `excluUseAr` × `roomCount`(pyeong_types join) × `dealYear` → 거래빈도 히트맵.
- 평택 실증 (253k):
  | 면적대 | 거래비중 | 방추정 |
  |---|---|---|
  | ~60㎡ | 45% | 소형 2-3방 |
  | **60-85㎡(국평)** | **47%** | **3방** ⭐ |
  | 85㎡+ | 8% | 4방+ |
  - **P1(2017) 전후 shift**: 소형 우세(51%) → **국평 3방 우세(49%)** = 반도체 가족 유입 신호.
- 산출: "활발 거래 규격" = 시대별·연령유입별 top 평형/방개수 (RQ 직접 답).

### 13.2 연령 코호트 ↔ 선호 규격 연결 (인구 × 실거래)
- 30-40대 가족 유입률(§12) vs 3방 국평 거래비중 시차상관.
- 가설: 엔지니어 가족 유입 → 3-4방 국평 수요 → 국평 거래·가격 프리미엄 ↑.

### 13.3 방 크기 분양시기별 변화 (평면도 OCR × buildYear)
- 방법: 평면도 OCR(로컬 Gemma) → 침실/거실/주방 mm → `buildYear` 회귀.
- 평택 분양면적 실증 추세 (거래기준 평균 전용):
  1985 49㎡ → 2005 **84㎡ (대형화 정점)** → 2015+ **72㎡ (소형화 회귀)**.
  → 방 크기도 유사 곡선 예상 (2000년대 확대 → 2010년대 효율화). OCR 로 방별 검증.

### 13.4 거실·부엌 공용공간 진화 + 예측 (핵심 novel)
- 방법: 평면도 OCR → 거실 m² / 주방·식당 m² → 분양시기 회귀 + 외삽.
- 가설: 거실/전용 비율 변화 (LDK 통합화, 발코니 확장 트렌드).
- 예측식: `거실크기(τ) = β₀+β₁·buildYear ± k·σ`, 2030/35 외삽.
- ⚠️ 평면도 mm 직접 = 평택 11단지, 나머지 NAVER 2D 자동추정(±20%, §4.8).

### 13.5 광주 근로자 아파트 공간 예측 (전이, §11+§12 종합)
```
광주_예측(공간요소, τ) =
   광주_baseline(τ=-5)
   + [평택_궤적(τ) − 평택(τ=-5)] × w          # 델타 전이
   + 연령유입 보정 (엔지니어 가족 코호트, §12)
   ± k·σ (다중도시 분산)
```
- 산출 (광주 반도체 가동 후 τ년):
  | 요소 | 예측 |
  |---|---|
  | 최활발 평형 | 60-85㎡ 국평 (평택 패턴 전이) |
  | 방 개수 | 3-4방 (가족 유입) |
  | 방/거실/부엌 크기 | OCR 회귀 외삽 + 시그마 |
  | 주차/세대 | 우상향 전이 |
- 웹: 시그마 슬라이더 → 광주 근로자 아파트 규격 [하한,점,상한] 실시간 (§2 목표).

### 13.7 ⭐⭐ 핵심 발견 — 1인 가구화 vs 중형 공급 "미스매치" (dry-run 검증됨)
> 단순 "반도체=3방 가족 수요" 서사를 데이터로 반증. 진짜 이야기 = **수요-공급 괴리**.

**3중 실증 (2015→2024, 평택)**:
| 신호 | 데이터 | 방향 |
|---|---|---|
| **1인 가구 비율** | 26.7% → **37.3%** (+10.6%p, 전국보다 빠름) | 1인화 ↑↑ |
| 청년(20-34) 인구 | +44% (가족층 +24%보다 빠름) | 1인화 압력 ↑ |
| **아파트 거래/공급** | 중형3방 40%→53%, 신축 57% 중형 | 가족형 지속 → |

→ **미스매치**: 가구의 37%가 1인인데 아파트 공급·거래는 중형 3방 중심.
- 해석 가설: (a) 청년 1인이 중형에 거주(룸셰어/여유) (b) 1인은 전월세·오피스텔·타지역으로 밀림
  (c) 공급이 인구구조 변화를 못 쫓는 lag (d) 반도체 가족 유입이 1인화를 부분 상쇄.
- **논문 각도**: "반도체 도시의 인구는 1인화하는데 아파트 공급은 가족형에 머무는 괴리" =
  단순 예측을 넘어 **정책 시사점**(1인용 소형 공급 부족) 도출.
- 광주 예측(§13.5)에 반영: 광주 근로자 아파트 = 가족형 국평 + **1인용 소형 병행 수요** 예측.

## 11. 전이 예측 — 평택 → 광주 (신규 클러스터 forecast)

> 광주 첨단3지구(363만㎡, 삼성 전공정, 2027 조성→~2030 가동) = 신규 반도체 클러스터.
> 평택의 궤적을 광주에 이식하여 미래 주거·인구를 예측.

### 11.1 사건시간 정렬 (Event-Time Alignment)
- 달력연도 아닌 **공장 가동 기준 상대연도 τ** 로 정렬.
- 평택 가동 τ=0 → 2017 / 광주 가동 τ=0 → ~2030 (offset ≈13년).
- **광주 2025 = τ−5 = 평택 2012** (둘 다 착공 前 greenfield). 사용자 검증 통찰.

### 11.2 기준선 동등성 검정 (Baseline Equivalence)
- "광주 2025 ≟ 평택 2012" 를 데이터로 실증 (가정 아님).
- 비교축: 인근 아파트 밀도 / 인구 규모·연령구조 / 기존 주거속성 / 토지이용.
- 표준화 차이(SMD) < 임계 → 전이 정당화. 차이 → 보정가중 w.
- 구조 대응: 광주 첨단3(신규)=평택 고덕(신규) / 첨단1·2(기존)=기존 평택.

### 11.3 델타 전이 예측식
```
광주(τ) = 광주_baseline(τ=−5) + [평택(τ) − 평택(τ=−5)] × w  ± k·σ
  Δ평택 = 평택 공장前후 변화 (절대값 아닌 변화량 이식)
  w = 기준선 동등성 보정 가중
  σ = 다중도시(평택+용인+화성+이천) 분산 → 시그마 통계 근거
  k = 시그마 (2.5/2.9/3.0/3.5) ← 웹 슬라이더
```
- ⚠️ σ 성립 전제 = **다중 반도체도시 학습** (평택 단독이면 "예시 계산").

## 12. ⭐ 연령대별 유입 벡터 + 취학아동 코호트 예측 (인구 심화)

> "30-40대 41%" 스칼라 → **전 연령 벡터 + 자녀 코호트 진행** 으로 확장.

### 12.1 전 연령 유입 벡터 (스칼라 → 벡터)
- 단일 "30-40대" 대신 **[0-4, 5-9, ..., 65+] 전 구간** 예측 벡터.
- 평택 실측 (2011→2024 순증):
  | 층 | 순증 | 시사 |
  |---|---|---|
  | 25-44 (부모/엔지니어) | +49,598 | 핵심 유입 |
  | 0-14 (자녀) | +1,649 | 소폭 (저출산 상쇄) |
  | 50-69 (부모세대·은퇴) | +84,000+ | 동반 유입 (예상 밖) |
- 웹: 단일 숫자 대신 **연령 피라미드 / 막대 분포** 표시.

### 12.2 ⭐ 부모-자녀 코호트 연동 (핵심 발견)
- 순증 비율만 보면 자녀 계수 0.033 (낮음) — **저출산이 가림**.
- **코호트 대각 추적** 이 진실: 2019 영유아 21,872 → 2024 초등 26,628 (**+22%**, 순유입).
- → 반도체 유입 가족 = **신생아 아닌 학령기(5-14세) 자녀 동반**.
- 계수: `가족유입계수 = Δ(학령 코호트 대각) / Δ(부모층 25-44)`.

### 12.3 취학 수요 시점 예측 (코호트 진행 → 상권/교육)
- 유입 자녀 코호트를 미래로 진행 (aging):
  ```
  광주 가동 τ=0 (2030) 유입 5-9세 → τ+5 (2035) 초등고학년/중등 → τ+10 (2040) 고등
  ```
- 예측 산출: 어린이집·유치원 수요 peak (τ=0~3), 초등 (τ=3~8), 중고등 (τ=8~13), 학원상권 (τ=5~12).
- → 논문 #3 "상권 분석" 을 **정량 시점 예측** 으로 이행.
